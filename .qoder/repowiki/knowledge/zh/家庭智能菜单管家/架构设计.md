- **技术栈**: 采用 Vite + React 19 + TypeScript 构建，使用 Tailwind CSS v4 进行样式设计，Zustand 管理全局状态，Dexie.js 封装 IndexedDB 实现本地数据持久化。
- **分层结构**: 
  - `src/algorithms/`: 核心业务逻辑层，包含基于权重评分的菜单生成算法 (`menuGenerator.ts`)、采购清单计算 (`shoppingList.ts`) 及数据校验。
  - `src/store/`: 状态管理层，通过 Zustand stores (`useMenuStore`, `useRecipeStore` 等) 协调 UI 与数据库交互。
  - `src/db/`: 数据访问层，定义 Dexie 数据库 schema 及种子数据初始化逻辑。
  - `src/components/`: UI 表现层，按功能模块 (Menu, Recipe, Shopping, History) 组织，复用 `ui/` 目录下的 Radix UI 基础组件。
  - `src/types/`: 类型定义层，统一管理 Recipe, Menu, History 等核心数据模型。
- **依赖方向**: UI 组件调用 Store Actions，Store 调用 Algorithms 和 DB 接口，Algorithms 依赖 Types 和 Config。
